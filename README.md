# ⚽ Featured Project

## Matchday Store

**Production-oriented ecommerce backend for a football club merchandise store**

**Django · PostgreSQL · Celery · Redis · Docker · CI/CD**

A realistic ecommerce MVP focused not on CRUD functionality, but on:

* transactional consistency,
* operational reliability,
* concurrency protection,
* observability,
* production-style deployment.

### Key Engineering Features

* transaction-safe checkout
* reservation-based stock model
* idempotent order processing
* race-condition protection with `select_for_update`
* structured JSON logging + request tracing
* Celery background workers with retry safety
* GitHub Actions CI/CD pipeline
* Dockerized production deployment
* 300+ automated tests including concurrency scenarios

### Engineering Focus

The project models real operational workflows:

* stock reservation,
* order lifecycle management,
* warehouse processing,
* async notifications,
* operational monitoring,
* deployment automation.

### Core Technical Challenges

#### Preventing Overselling

Implemented protections:

* `transaction.atomic()`
* `select_for_update()`
* deterministic lock ordering
* idempotency keys
* database constraints
* concurrency tests

#### Reliable Checkout Flow

The checkout system safely handles:

* duplicate submits,
* browser refreshes,
* network retries,
* parallel requests,
* async task failures.

### Tech Stack

* Python 3.12
* Django 5
* PostgreSQL 16
* Celery + Redis
* Docker + Docker Compose
* Nginx + Gunicorn
* GitHub Actions
* Sentry
* Structured JSON logging
