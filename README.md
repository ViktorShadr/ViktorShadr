### 📊 Deribit Price Tracker  
**FastAPI · PostgreSQL · SQLAlchemy · Celery · Redis · Docker**

Сервис автоматического сбора и предоставления рыночных данных  
(BTC/USD, ETH/USD) с криптобиржи Deribit.

- интеграция с внешним REST API  
- периодический сбор данных (Celery, 1 минута)  
- REST API для актуальных и исторических цен  
- retry-механика и защита от дубликатов  
- unit-тесты, Docker-окружение  

> Акцент на надёжность фоновых задач и корректность данных при сбоях внешнего API.

👉 https://github.com/ViktorShadr/deribit-price-tracker
